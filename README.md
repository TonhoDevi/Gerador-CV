# Meu Currículo

Gerador de currículo em formato Word (.docx) usando JavaScript e a biblioteca `docx`.

## Como usar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Execute o script:
   ```bash
   node main.js
   ```

3. O arquivo `curriculo_antonio_henrique.docx` será gerado na pasta.

## Personalização

Edite o arquivo `main.js` para alterar:
- Dados pessoais
- Experiência profissional
- Projetos
- Habilidades
- Formação
